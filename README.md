# Приложение Погода

Приложение можно посмотреть [здесь](https://lisa-lpt.github.io/otus-js-lipatova-2/)

Приложение сделано для курсов otus.

## Функционал приложения

При переходе в приложение пользователь видит главную страницу с меню.
В меню есть три вкладки :

- Главная
- Прогноз погоды
- О приложении

Если путь в url несуществующий, то пользователь получит "Страница не найдена".

### Прогноз погоды

Пользователь может посмотреть погоду по названию города и геолокации.Еще на странице показаны, ранее просмотренные, города.
Пользователь может вернуться к прогнозу уже просмотренного города, а также очистить историю.

При введении города пользователь получает данные о погоде:

- Погода
- Температура
- Ощущается как
- Давление
- Влажность

а также карту введенного города.

В истории хранится не более 10 городов, а просматриваемый сейчас выделен синим.
